# Sandhiya Virtusa Internship Tasks

This repository contains solutions to 9 programming tasks implemented in Java, TypeScript, and JavaScript.

## Questions & Languages

1. **Calculate string length without length() method** - Java (`Java/Q1_StringLength.java`)
2. **Find most frequent character in a string** - Java (`Java/Q2_MostFrequentCharacter.java`)
3. **Count total number of vowels in a string** - Java (`Java/Q3_CountVowels.java`)
4. **Calculate average of elements in an array** - TypeScript (`TypeScript/Q4_Average.ts`)
5. **Check whether a number is even or odd** - TypeScript (`TypeScript/Q5_EvenOdd.ts`)
6. **Check whether a number is integer or float** - TypeScript (`TypeScript/Q6_IntegerOrFloat.ts`)
7. **Convert integer to Roman numeral** - JavaScript (`JavaScript/Q7_IntegerToRoman.js`)
8. **Generate random number between min and max** - JavaScript (`JavaScript/Q8_RandomNumber.js`)
9. **Convert RGB values to hexadecimal color code** - JavaScript (`JavaScript/Q9_RGBToHex.js`)

## Commands to Run Programs

### Java Programs
Compile and run using Java standard commands:

```bash
# Q1: String Length
javac Java/Q1_StringLength.java
java -cp Java Q1_StringLength

# Q2: Most Frequent Character
javac Java/Q2_MostFrequentCharacter.java
java -cp Java Q2_MostFrequentCharacter

# Q3: Count Vowels
javac Java/Q3_CountVowels.java
java -cp Java Q3_CountVowels
```

### TypeScript Programs
Run directly using `ts-node` or compile with `tsc`:

```bash
# Q4: Average
npx ts-node TypeScript/Q4_Average.ts

# Q5: Even or Odd
npx ts-node TypeScript/Q5_EvenOdd.ts

# Q6: Integer or Float
npx ts-node TypeScript/Q6_IntegerOrFloat.ts
```

### JavaScript Programs
Run using Node.js:

```bash
# Q7: Integer to Roman
node JavaScript/Q7_IntegerToRoman.js

# Q8: Random Number
node JavaScript/Q8_RandomNumber.js

# Q9: RGB to Hex
node JavaScript/Q9_RGBToHex.js
```
